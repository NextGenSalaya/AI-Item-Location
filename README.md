# Makro AI Item Location — ศาลายา

เว็บค้นหาสินค้า ดูรายละเอียดและรูปสินค้า แสดงตำแหน่งบนผัง 3D และจัดเส้นทางสำหรับรายการซื้อ ใช้ได้ทั้งคอมพิวเตอร์และโทรศัพท์ที่รองรับ WebGL

## GitHub Pages (Public)

ที่อยู่เมื่อเผยแพร่สำเร็จ: https://nextgensalaya.github.io/AI-Item-Location/

ในรีโป เลือก **Settings → Pages → Source → GitHub Actions** แล้ว workflow `Publish Makro 3D to GitHub Pages` จะสร้างและเผยแพร่เว็บทุกครั้งที่อัปเดต `main` หรือสั่ง Run workflow ในหน้า Actions

เว็บไซต์สาธารณะใช้ข้อมูลจริงจากสาขา 15,768 แถว พร้อมรายละเอียดสินค้าและลิงก์ภาพ Makro PRO ตามข้อมูลต้นฉบับ ภาพและไลบรารี 3D ต้องเชื่อมต่ออินเทอร์เน็ต ตำแหน่งที่ไม่มีพิกัดยังไม่สามารถนำทางได้ ข้อมูลนี้เป็นชุดข้อมูลที่นำเข้า ไม่ใช่สต็อก ราคา หรือโปรโมชั่นแบบสด

ส่วนจัดรายการซื้อบน Pages ใช้ชุดรายการตามประเภทร้าน แยกเปิดร้านใหม่/เติมของร้านเดิม และเลือกตัวเลือกจากสินค้าจริง ไม่เรียก Claude และไม่ส่งคำขอไป localhost ปริมาณเป็นคำแนะนำตั้งต้น ต้องตรวจสอบให้เหมาะกับธุรกิจ

## รันบนเครื่อง

ใช้ Python 3.10 ขึ้นไป:

```sh
python -m pip install anthropic
python store3d/serve.py 8765
```

เปิด http://localhost:8765/ เซิร์ฟเวอร์นี้รับเฉพาะการเชื่อมต่อจากเครื่องเดียวกัน ถ้าไม่ตั้งค่า Claude จะใช้ชุดรายการตามประเภทร้าน การใช้ Claude ต้องตั้งค่าบริการและโมเดลที่บัญชีรองรับแยกต่างหาก ห้ามใส่ API key ในไฟล์เว็บหรือ commit ลง GitHub

## สร้างเว็บแบบเดียวกับ Pages

```sh
python build_pages.py
node --experimental-vm-modules tests/pages.test.mjs
python -m http.server 8766 --directory dist --bind 127.0.0.1
```

เปิด http://localhost:8766/ การสร้างเว็บใช้ Python standard library และไม่ต้องใช้ API key ผลลัพธ์อยู่ใน `dist/` โดยเผยแพร่เฉพาะหน้าเว็บ โมดูลจัดรายการ และข้อมูลแสดงผล ไม่เผยแพร่เซิร์ฟเวอร์ Python หรือข้อมูลตรวจแก้หมวดหมู่ภายใน

## แหล่งข้อมูลและการอัปเดต

เริ่มต้นจากแอพ `store3d` ของโครงการ NextGenSalaya/AI-Location สาขาโค้ด `claude/store3d` และข้อมูลที่ให้บริการจากแอพในเครื่องเมื่อ 15 ตุลาคม 2026

- `store3d/index.html`: หน้าเว็บและผัง 3D
- `store3d/data/`: ข้อมูลตำแหน่ง สินค้า รายละเอียด และผัง
- `store3d/starter_kits.py`, `ai_planner.py`: ชุดรายการและตัวเลือกสินค้าจริง
- `build_pages.py`: สร้างชุดรายการล่วงหน้าและเว็บสำหรับ Pages
- `.github/workflows/pages.yml`: ทดสอบและเผยแพร่เว็บ

หลังเปลี่ยนข้อมูลสินค้า/ตำแหน่ง ให้รัน build และตรวจสอบเส้นทางกับหน้างานก่อนเผยแพร่ ข้อมูลและรูปสินค้าไม่ควรถูกอ้างว่าเป็นข้อมูลเรียลไทม์ของสาขา
